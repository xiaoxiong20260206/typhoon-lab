# v2.1 沉浸简洁版 · 本地验收

用户选择「直接做沉浸简洁版」。本轮按渐进展开设计，保留全部进阶操作，不改变气象模型。

## 交付范围

- 全屏地图、小型风暴信息条、主创建入口与镜头/声音；实验、显示、详细观测按需打开原生抽屉。
- 创建窗口默认只展示阶段与路径；详细参数折叠。抽屉和影院都有退出路径；关闭恢复入口焦点。
- 侧光云体、柔边风眼开口、径向云面、差速旋转、播放时电影巡航；仍是视觉示意。
- 分级几何、复用风圈/轨迹 BufferGeometry、缓存轨迹、标签节流、关闭的抽屉不刷新重型图表。
- 原布局通过 `?layout=classic` 保留，所有布局与渲染模式共用模拟状态。

## 量化对照

同一独立 Chrome，1440×960，8 系统，全域，自动画质：

| 指标 | v2.0 基线 | v2.1 |
|---|---:|---:|
| 首屏可见控件（按钮/选择/输入） | 32 | 12 |
| 绘制三角形 | 174200 | 32344 |
| Draw calls | 33 | 33 |
| 帧间隔中位数 | 16.7ms | 16.7ms |
| 帧间隔 P95 | 16.7ms | 16.8ms |

三角形减少约 81.4%，不等于帧率提高 81.4%。本机测试受刷新率限制，两者均约 60 帧；没有设备无关 FPS 承诺。数据见 `Output/before-performance.json` / `Output/after-performance.json`。

## 验证

- `npm test`：33 项通过。
- `refinement.test.mjs`：24 项通过，包含抽屉焦点、二维/三维同一 frame 切换、手机单屏/横屏、影院退出、进阶创建可达、关闭图表不重建、再次打开刷新、顶点缓冲复用。
- `theater.test.mjs`：26 项，继续检验 WebGL/音频/8 系统/地理点击/回退；`verify-browser.mjs`：51 项原规则与交互。
- 初次并行浏览器回归中声音信号检查超时，未计作通过；之后独立重跑通过，未更改音频实现，也未将超时原因确认为产品问题或工具问题。
- 先写并运行沉浸布局、云体预算、隐藏图表回归，确认旧实现失败后再实现。追加影院退出回归捕获到事件顺序问题，修复为显式 `lab:cinema-change` 通知。
- 手工查看桌面、手机、风眼截图，修正实体山峰感、眼口遮挡；截图仅留本地。
- 内置浏览器 `new_tab` 仍超时，使用项目既有独立临时 Chrome。没有修改运行模式或重启宿主。

## 不变的边界

固定命名、编号、热带风暴命名阈值、海陆判断、七/十/十二级风圈、登陆减弱、变性停编与区域约束仍按原模型。完全消散后复活、吞并、藤原效应、真实体积云及数值预报均未新增。
