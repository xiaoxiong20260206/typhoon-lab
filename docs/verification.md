## 工具限制与科学限制

MyFlicker 内置浏览器 `new_tab` 返回 `ELECTRON_HOST_NOT_AVAILABLE` / `EXECUTION_TIMEOUT`，daemon 可达但宿主桥未连接。没有重启或更改运行模式。浏览器交互、截图及错误检查改用 HTML 截图技能的独立 Puppeteer/Chrome 本地渲染方式完成，不把内置浏览器连接报告为已修复。

这是科普级简化模型：情景引导路径、区域约束、后期能量衰减和气压/雨强都是近似；不是数值天气预报。云系作视觉增强，不是实测卫星图。气象边界与来源详见 `guide.html`。
