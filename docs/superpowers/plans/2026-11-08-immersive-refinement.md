# 沉浸简洁版 Implementation Plan

> 执行方式：用户已选择「直接做沉浸简洁版」，在本会话按 executing-plans 分步实施。工作目录没有 Git 仓库，不创建 worktree、不提交开发记录；远端只按 AGENTS.md 发布白名单。

**Goal:** 减少首屏操作负担，让云体更有纵深，并降低多系统渲染开销。

**Architecture:** 气象模型不变。新增 shell.js 管理抽屉、精简观测条与原控件复用；theater.js 保留 WebGL 回退，新增云体细节预算与几何缓存。`?layout=classic` 保留原布局供对照和规则回归。

**Tech Stack:** 原生 DOM/CSS、Three.js r128、Web Audio、Node test、现有 Puppeteer。

## 已确认的设计

- 默认全屏地图，首屏保留创建、镜头、声音、播放，以及名字/等级/风速/气压；环境、系统管理、详细观测、图层画质按需展开。
- 创建仍复用工坊；地图直接落点入口收进实验抽屉。抽屉可 Escape 关闭、恢复焦点，手机同样可达，不丢功能。
- 视觉采用深海、银灰云体、少量暖色操作强调；不增加全屏泛光、自动播放声音或频繁闪电。眼墙有更紧凑的开口、侧光阴影、内外云层差速和电影巡航镜头。
- 暂停/减少动态效果/后台遵守现有约束。云圈视觉示意与风圈地理半径分开。
