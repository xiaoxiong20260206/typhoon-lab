# 西北太平洋台风实验室 Implementation Plan

> 执行方式：当前会话内按任务实现。用户已完成多轮需求确认并明确要求开始制作。新空目录，没有既存 Git 分支或需要隔离的代码；不创建远端、不发布。

**Goal:** 提供可交互、可回放的西北太平洋科普级台风生命周期模拟器。

**Architecture:** 原生 ES modules，纯函数气象规则、确定性按小时演化、地理海陆判断与 Canvas 地图分离。预计算快照用于暂停、倍速和回放；环境修改重新计算同一实验，编号和名字由实验内部计数器分配。地图和命名数据本地保存，运行无需第三方网络。

**Tech Stack:** HTML、CSS、Canvas 2D、JavaScript、Node 内置测试及静态服务。

## 已确认规则

- 地图仅西北太平洋（含南海、周边陆地与北部变性区域），不跨洋，不移出范围。
- 扰动编号 90W–99W，热带低压顺序编号 01W 起，达到 17.2 m/s 才按固定表命名。
- 分类采用中国台风强度六级及风力等级阈值；编号标注 JTWC 风格，是实验编号而非实况。
- 七/十/十二级风圈分别在 13.9/24.5/32.7 m/s 出现，低于阈值消失；半径与环流规模有关且不对称。
- 强度和规模独立；增强使云系更紧实，雨区与风圈分别表现。
- 海上同样有风雨；陆地只有被实际风雨场覆盖才受影响。
- 登陆逐步减弱，短暂登陆再入海可恢复；持续登陆最终消散。
- 北部冷空气触发温带变性、停编，不立刻删除；温带气旋继续风雨并逐渐消散。
- 名字、编号、类别、级数、m/s、hPa 与风圈半径同步显示。
